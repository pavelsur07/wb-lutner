# План: интеграция Яндекс Маркета (третья площадка)

Дата: 11.11.2026 · Статус: **этап 1 задеплоен 11.11.2026 (c79c9e0); этап 2а задеплоен 12.11.2026 (e1f2f22)**

Решения: один кабинет / один магазин; настройки Маркета — в БД (`system_state`),
ключи WB/Ozon остаются в `.env`; вкладка UI «Настройка» общая (график отгрузок + Маркет).

## Этап 1. Подключение и проверка ✅ задеплоено 11.11.2026

- `lib/ym_api.py`: клиент (`Api-Key`, ретраи на 420/5xx, листание `pageToken`),
  настройки `ym_api_key / ym_business_id / ym_campaign_id / ym_warehouse_id`,
  `check()` → `GET v2/campaigns` + `POST v2/businesses/{id}/warehouses`,
  результат в `ym_check`; один магазин/склад подставляется сам.
- UI `/ui/settings/ym`: форма, «Сохранить и проверить», выбор магазина/склада,
  ключ только маской. CSRF как у графика отгрузок.
- `tests/test_ym_api.py`.

Деплой: только код, миграций нет. После — открыть страницу, вставить ключ, проверить.

## Этап 2. Остатки

Проверено 12.11.2026 по документации и на проде:
- Ключу нужен доступ **«Управление товарами и карточками»** (`offers-and-cards-management`) или
  «Полное управление кабинетом»: без него 403 на каталог, чтение и запись остатков.
  На проде ключ перевыпущен 12.11 (`••••cce1`), всё отвечает.
- Групп складов нет → методы v3: чтение `POST v3/businesses/{id}/offers/stocks`
  (`partnerWarehouseId`, ≤100/стр.), запись `POST v3/businesses/{id}/offers/stocks/update`
  (`skuItems[]: {sku, partnerWarehouseId, count}`, ≤2000 за запрос, **50 запросов/мин**).
- Каталог кабинета общий на 3 магазина (209 товаров); offerId = артикул Lutner у 80,
  остальные — другие бренды и 10 наборов Cort (не 1:1, пропускаем).
- Остаток — как у WB/Ozon: `store_spb` + `lib/stock_rules.sellable` (<5 → 0, >20 → 20).
